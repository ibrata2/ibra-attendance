# بصمة IBRA

برنامج حضور وانصراف الموظفين ببصمة الوجه، للمحلات والشركات اللي عندها فرع واحد أو أكثر.

## فكرة البرنامج
الموظف يكتب الكود مالته على الحاسبة، والبرنامج يفتح الكاميرا ويتأكد من وجهه قبل ما يسجل الحضور أو الانصراف. البرنامج يحسب التأخير والغياب والانصراف المبكر، ويطلع الراتب الصافي لكل موظف آخر الشهر.

## الأجزاء
- **برنامج الحاسبة (ويندوز):** البصمة، والموظفين، والورديات، والخصومات، والتقارير، وتصدير Excel. يشتغل حتى بدون إنترنت ويرفع التسجيلات من يرجع النت.
- **تطبيق المدير (ايفون):** يعرض السجل المباشر مع صور الوجوه والفرع والوقت، ولوحة اليوم، والرواتب، ويطلع إشعار بكل بصمة.

## الفائدة
ينهي التلاعب بالبصمة (البصمة عن غيرك أو بصورة)، ويوفر على صاحب المحل حساب الرواتب والخصومات يدوياً، ويخليه يتابع كل فروعه من الموبايل.
